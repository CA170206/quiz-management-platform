# 🎯 Quiz Management & Online Assessment Platform

A full-stack Quiz Management & Online Assessment Platform that enables students to take online quizzes while providing administrators with powerful tools to manage quizzes, users, questions, and analytics.

---

## 🚀 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- React Router DOM
- Axios
- React Hook Form
- Recharts

### Backend
- Node.js
- Express.js
- JWT Authentication
- bcrypt

### Database
- PostgreSQL

### Tools
- Git & GitHub
- Postman
- VS Code

---

## ✨ Features

### Student Module
- User Registration & Login
- Browse Available Quizzes
- Quiz Attempt with Timer
- Automatic Score Calculation
- Result Review
- Attempt History
- Performance Dashboard
- Leaderboard

### Admin Module
- Secure Admin Login
- Dashboard Analytics
- User Management
- Quiz Management
- Category Management
- Question Management
- Performance Reports
- Publish / Unpublish Quizzes

## 🛠️ Installation

### Clone Repository

```bash
git clone https://github.com/CA170206/quiz-management-platform.git
```

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```
