# Quiz Management & Online Assessment Platform

A full-stack Quiz Management Platform built using the MERN stack.

## Tech Stack

- React
- Tailwind CSS
- Node.js
- Express.js
- PostgreSQL
- JWT Authentication

## Features

- Student Authentication
- Admin Dashboard
- Quiz Management
- Category Management
- Question Management
- Quiz Attempt System
- Leaderboard
- Analytics
